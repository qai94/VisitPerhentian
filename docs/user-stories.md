# User Stories

## US1 - Explore island activities
As a first-time visitor, I want to browse descriptions and images of activities on Pulau Perhentian, so that I can decide which experiences interest me before planning my trip.

Acceptance criteria:
- The activities page includes kayaking, snorkeling, jungle trekking, and scuba diving.
- Each activity includes a name, image, and description.


## US2 - Compare accommodation options
As a traveller choosing where to stay, I want to view accommodation grouped by island with indicative prices and provider links, so that I can compare options and visit a provider's website for current details.

Acceptance criteria:
- Accommodation is grouped under Perhentian Besar and Perhentian Kecil.
- Each option includes a property name, image, description, indicative price, and external website link.
- Prices are treated as static demonstration information, not live availability or a confirmed booking offer.

## US3 - Practise completing an enquiry
As a visitor trying the prototype, I want the enquiry form to identify missing or invalid details and show a demonstration confirmation when my input is valid, so that I can understand the intended enquiry flow.

Acceptance criteria:
- Missing required fields and invalid email or phone-number formats produce validation feedback.
- The message must contain at least 10 characters.
- Selecting "Others" reveals a required explanation field.
- Valid fictional input displays a simulated confirmation; no enquiry is sent to or stored on a server.


## US4 - Read the privacy policy
As a visitor reviewing the enquiry form, I want to open the privacy policy, so that I can understand the site's stated approach to handling contact information before entering any details.

Acceptance criteria:
- The contact page includes a link to the privacy policy.
- Following the link opens the site's privacy policy page.
- The project documentation explains that the current enquiry form is a demonstration without server-side delivery or storage.
